**Auto model detection (2026-07-27):** PVS no longer needs manual model selection. It reads the machine's loaded program via the Sony serial **`C3P` command** ("Request of PWB Data Names Assigned for Production", SI-E2000 manual §7.3.2). Machine replies with a `D0<name>.PWn` data message; PVS captures the name (extension is cell-specific `.PW1`..`.PW4`, NOT `.PWB` — match `.PW`). Example: M4 → `L307_L313 - B SIDE _Cell4.PW4`, parsed to model=first `L\d{3}` (L307), side=`B SIDE`→B. Coordinator `AutoDetectModelAsync` (30s timer) prefers the C3P program from ANY answering machine, falls back to `GetCurrentLotAsync` (latest DailyProductionCount for the line). Note: on Line 1 only **M4 answers C3P; M1–M3 return A4E00** (reject it) — one machine is enough.
